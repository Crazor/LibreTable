# Game rules specifications

One folder per game: `docs/games/<game-id>/rules.md`, written before implementation and signed off by the architect.

Each spec contains:

1. **Standard ruleset** with its source (where an authoritative one exists).
2. **House-rule options**: typed (bool, enum, bounded number), with defaults and incompatibilities.
3. **Scoring and end of game**, including multi-round scoring.
4. **Example games** that become golden replays.
5. **Licence note**: public domain or licensed; for commercial relatives, the public-domain ancestor we implement.
